# Prerit Agarwal - Personal Portfolio

A personal portfolio website built with React, React-Bootstrap, and Sass. It showcases personal details, resume, services, and an interactive FAQ and Contact section.

## Features

- **Fully Responsive:** Adapts to all screen sizes using Bootstrap 5.
- **Dynamic Content:** Powered by React components (`AboutUs`, `Resume`, `Services`, `FAQs`, `Contact`).
- **Interactive Elements:** Includes scroll animations (WOW.js), smooth scrolling, and typewriter effects.
- **Theme Switcher:** Allows toggling between color themes dynamically using Sass variables.
- **Progressive Web App:** Ready to be installed on devices, configured via `manifest.json`.

## Built With

- React (v19)
- React-Bootstrap
- Sass
- WOW.js
- React-Scroll
- Isotope Layout

## Available Scripts

In the project directory, you can run:

### `npm start`

Runs the app in the development mode.\
Open [http://localhost:3000](http://localhost:3000) to view it in the browser. Before running, run `npm install --legacy-peer-deps` to install dependencies.

### `npm run build`

Builds the app for production to the `build` folder.\
It correctly bundles React in production mode and optimizes the build for the best performance.

### `npm run deploy`

Deploys the application directly to GitHub Pages.
